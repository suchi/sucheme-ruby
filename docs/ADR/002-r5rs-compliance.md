# ADR 002: R5RS準拠アプローチ

## ステータス
採用

## コンテキスト
どのScheme標準に準拠するかを決定する必要があります。

## 決定
R5RS（Revised^5 Report on the Algorithmic Language Scheme）に準拠します。

## 理由
- **安定性**: R5RSは1998年以来変更がなく安定している
- **シンプル**: R6RS/R7RSより小さく実装しやすい
- **教育的**: 学習目的に最適なサイズ

## 実装方針
- 全ての標準手続きを実装
- 末尾呼び出し最適化（TCO）を実装
- syntax-rulesマクロを実装
- call/ccを実装（限定的）

## 制限事項
- 完全な継続（フルcall/cc）はFiberまたはgem使用を要検討
- 数値タワー: 複素数は未実装
