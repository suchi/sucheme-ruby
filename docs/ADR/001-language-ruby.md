# ADR 001: 実装言語にRubyを選択

## ステータス
採用

## コンテキスト
Schemeインタープリタの実装言語を選択する必要があります。

## 決定
Rubyを実装言語として選択します。

## 理由
- **動的型付け**: Schemeの動的な値を自然に表現可能
- **組み込みの多倍長整数**: SchemeのExact整数をそのまま利用
- **Rational型**: SchemeのExact有理数をそのまま利用
- **ブロック/クロージャ**: Schemeの環境を自然に表現
- **例外処理**: エラー処理が自然
- **StringIO**: 文字列ポートの実装が容易
- **throw/catch**: call/ccの限定的な実装に利用

## 結果
- Ruby 3.2+を使用
- Gemfileで依存関係を管理
- RSpecでテスト
